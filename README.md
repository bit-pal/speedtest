# Замер скорости интернета (Python)

Скрипт на Python последовательно выполняет 10 запросов к указанному адресу (например, к тяжёлой картинке), дожидается полного скачивания каждого ответа и выводит:

- время и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- итоговую скорость в МБ/с (и в Мбит/с для справки).

Используется только стандартная библиотека Python, ставить ничего не нужно.

## Требования

Python 3.9 или новее.

## Запуск

```bash
git clone https://github.com/bit-pal/speedtest.git
cd speedtest

# с адресом по умолчанию (картинка ~14.7 МБ с Wikimedia)
python speedtest.py

# со своим адресом
python speedtest.py https://example.com/big-image.jpg
```

### Параметры

| Параметр | Описание | По умолчанию |
|---|---|---|
| `url` | адрес, который нужно скачивать | картинка с Wikimedia |
| `-n`, `--requests` | число последовательных запросов | 10 |
| `-t`, `--timeout` | таймаут одного запроса, в секундах | 60 |

## Пример вывода

```
URL: https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
Запросов: 3

[ 1/3]    14.68 МБ за  6.507 с  ->     2.26 МБ/с
[ 2/3]    14.68 МБ за  6.218 с  ->     2.36 МБ/с
[ 3/3]    14.68 МБ за  6.456 с  ->     2.27 МБ/с

==================================================
Успешных запросов:     3 из 3
Среднее время запроса: 6.394 с
Скачано всего:         44.04 МБ (44038422 байт)
Скорость:              2.30 МБ/с (18.37 Мбит/с)
```

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела ответа.
- Скорость = суммарный объём / суммарное время всех успешных запросов.
- 1 МБ = 1 000 000 байт.
- Если запрос завершился ошибкой, он выводится в консоль и не учитывается в итогах.
